🌊 Water Slider Jump - Enhanced
疾走感あふれるウォータースライダーを舞台に、迫りくる障害物をジャンプで避ける爽快アクションゲームです。

🎮 ゲーム概要
プレイヤーを操作して、スライダー上に現れる障害物をタイミングよくジャンプで避けてください。時間が経つにつれてスピードが上昇し、スコアに応じて背景が「昼 → 夕方 → 夜」とダイナミックに変化します。

🕹 操作方法
PC:

Space キー または マウス左クリック でジャンプ

スマートフォン/タブレット:

画面をタップ でジャンプ

✨ 特徴 (改良版のポイント)
Game Feelの向上: プレイヤーに目を付け、ジャンプ中に回転を加えることで動きを可視化。

ダイナミックな演出: Web Audio APIによる効果音と、粒子シミュレーションによる水しぶきエフェクト。

レスポンシブ対応: PC・モバイルの両方で快適にプレイ可能。

ハイスコア保存: ブラウザのLocal Storage機能により、過去の最高得点が保存されます。

🛠 技術スタック
Frontend: HTML5, CSS3, JavaScript (Vanilla JS)

Sound: Web Audio API (コード内で波形を生成しているため、外部音声ファイル不要)

Rendering: requestAnimationFrame による 60fps の滑らかな描画

🚀 セットアップ
特別なサーバー設定は不要です。

index.html として保存します。

ブラウザでファイルを開くだけでプレイ可能です。

💡 開発者へのヒント
さらに改造したい場合は、コード内の以下の数値を調整してみてください：

state.speed: 初期速度

state.velocity = 18: ジャンプ力

state.score === 15: ステージが切り替わるスコアのタイミング
